# 基本概念

## 架构

Tvvins 是一个基于 Node.js 的一体化 Web 应用框架。不同于常见的 MVC 架构的框架，Tvvins 的核心理念是一次实现，处处调用。基于这样的理念，业务逻辑的实现核心是`服务 ( Server )`。通过服务调度中心，可以在任何地方对服务进行调用，也可以通过装饰器，将服务暴露给外部服务进行调用。最棒的是，由于生态的共生，我们通过在编译阶段进行服务收集，所有的服务都可以直接( ESM 方式引入 )在前端进行使用。

目前我们通过官方内置插件，实现了对`http`、`websocket`、`grpc` 等协议进行服务外部化调用的实现。

## 服务 ( Server )

`服务 ( Server )`是 Tvvins 框架的核心概念，负责处理各种业务逻辑。每个服务都有一个唯一的名称，通过名称可以在任何地方对服务进行调用。

## 插件 ( Plugin )

插件 ( Plugin )是 Tvvins 框架的扩展机制，通过插件可以实现对框架的功能进行扩展。

## 模块 ( Module )

`模块 ( Module )`是 Tvvins 框架的组织单位，每个模块都有一个唯一的名称，通过名称可以在任何地方对模块进行调用。`服务 ( Server )` 和 `插件 ( Plugin )` 都会在配置阶段注册到 `模块上`。一个单一的模块就可以运行，如果你需要复用，讲若干`服务 ( Server )` 和 `插件 ( Plugin )`封装进一个模块，这个模块可以作为主模块的子模块，来运行封装的功能。

## FAQ

Q: 如何区分服务和插件？

A: 我们对服务的定位是处理业务逻辑，插件的定位是扩展框架的功能。比如我们通过 `http` 插件，对 `http` 请求进行监听，并通过装饰器，使得`服务 ( Server )`的实例方发成为接口的实现。而服务，应该是对应用以调用处理具体事务的集合。
